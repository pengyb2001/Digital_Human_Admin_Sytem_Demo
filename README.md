# 数字人后台管理系统

## 项目简介

数字人后台管理系统是一个用于管理数字人资产的后台管理平台。系统从"管理文件"转变为"管理人物（Face ID）"，实现一人多形象的聚合管理，强化合规风控，提升运营效率。

## 核心功能

### 1. 库区隔离
- **公有数字人**：所有用户可见的数字人资产
- **私有数字人**：仅定制者可见的定制数字人资产

### 2. 列表重构
- 引入 Face ID 作为人物唯一标识
- 采用折叠列表（Tree Table）交互
- 父子层级结构：人物维度（父级）和形象维度（子级）

### 3. 字段升级
- **人物维度字段**：
  - Face ID（必填，相同人脸必须使用同一ID）
  - 主播名称（对内）
  - 对外人物名
  - 类型（自研视频数字人、自研图片数字人、腾讯云数字人）
  - 性别、年龄
  - 授权开始/结束时间
  - 资产统计
  - 所属客户（仅私有库）

- **形象维度字段**：
  - 形象Key（唯一标识）
  - 对外形象名称（格式：对外人物名-特征）
  - 版式（横版/竖版）
  - 风格、赛道
  - 上架状态（待上架/已上架/已下架）
  - 详细参数（职业、姿势、比例、季节、场景、支持上传背景、宽、高）

### 4. 搜索与筛选
- **搜索功能**：
  - 人物搜索（Face ID/主播名称/对外展示名称，模糊匹配）
  - 数字人Key搜索（精准匹配）
  - 所属客户搜索（仅私有库，模糊匹配）

- **筛选功能**：
  - 版式：全部/横版/竖版
  - 授权状态：全部/生效中/即将过期（<30天）/已过期（带颜色提示）
  - 上架状态：全部/待上架/已上架/已下架
  - 更多筛选：性别、年龄、风格

### 5. 自动化逻辑
- **上传自动读参**：上传时自动读取视频参数（版式、宽、高等）
- **过期自动下架**：系统每日检测授权时间，到期自动下架并记录原因

### 6. 新增/编辑/删除
- **人物管理**：支持新增、编辑、删除人物
- **形象管理**：支持新增、编辑、删除形象
- **删除校验**：已上架的形象不允许删除，需先下架

## 技术栈

- **React 18.2.0** - 前端框架
- **Ant Design 5.12.0** - UI组件库
- **Vite 5.0.8** - 构建工具
- **Day.js** - 日期处理
- **React Router** - 路由管理

## 功能说明

### 授权过期检测

系统会自动检测授权过期状态：
- **生效中**（绿色）：授权未过期且剩余天数 > 30天
- **即将过期**（橙色）：授权剩余天数 ≤ 30天
- **已过期**（红色）：授权已过期

系统每日自动检测，到期自动下架并记录原因。

### 上架状态管理

- **待上架**：上传后默认状态，运营人员完善标签、确认效果
- **已上架**：点击上架后，系统开始每日检测授权时间
- **已下架**：
  - 人工下架：运营发现模型有问题，手动点击下架
  - 系统下架：授权过期自动下架，记录原因"授权过期"

## 注意事项

1. **Face ID唯一性**：相同人脸必须使用同一Face ID，系统会校验重复
2. **删除限制**：已上架的形象不允许删除，需先下架
3. **授权时间**：系统会自动检测授权过期，建议及时更新授权信息
4. **形象命名**：对外形象名称统一格式为"对外人物名-特征"
